##### Column: clade

The result of the clade assignment of a sequence, as defined by Nextstrain.

The clade is taken from the closest node on the phylogenetic tree after phylogenetic placement. See documentation for more details.

When the tree is ready, a circle before the clade shows the color of the clade on the tree, when the tree is colored by clade. Other clade columns, such as the Pango lineage, show the colors of the tree coloring by that column. When the dataset sets no color for a value, the tree chooses the color from the values in the tree, so this color can differ between runs.
